# Paper collection

This folder is the project's canonical paper source.

- `CATALOG.md` lists both local PDFs and metadata-only references.
- Put each acquired `*.pdf` in this folder.
- Start a PDF filename with its catalog `ShortID` so AgentUI can join the file to its metadata.

AgentUI shows `PDF` for a local file and opens it in the built-in PDF viewer. A metadata-only row is marked `MISSING`, is not clickable, and never opens an external website.
