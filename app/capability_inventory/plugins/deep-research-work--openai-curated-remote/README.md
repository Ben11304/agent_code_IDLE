# Deep Research

Deep Research investigates complex questions and presents evidence-backed findings with
descriptive source links. The artifact fits the request, whether a report, presentation,
spreadsheet, Site, or another suitable format. Data-heavy charts include reusable
underlying data in an XLSX workbook unless the user restricts additional files or data
sharing.

Ask for Deep research in your own words, use `$deep-research`, or select Deep research in Work mode. A general request to research a topic should not start Deep Research.

Use it to explore unfamiliar topics, compare options, reconcile conflicting evidence,
and support consequential decisions with current, authoritative sources. Each report
presents clear findings, relevant context, and citations tailored to the question.
